Saturday · Core & Weak Points

周六 · 核心 + 补弱项 中

热身 8min ｜ 核心循环 25min + 补弱项 15min ｜ 拉伸 12min

核心循环（25 min，×3 轮）

平板支撑45s · 休45s
  • ✓ 肘部在肩下对齐
  • ✓ 肚脐拉向脊柱
  • ✗ 臀部下沉 / 抬高
侧平板30s/侧 · 休30s
  • ✓ 肘部在肩正下方
  • ✓ 身体从头到脚直线
  • ✗ 臀部下沉 / 脚没叠放
鸟狗式10次 · 休30s
  • ✓ 核心收紧防下背下垂
  • ✓ 缓慢控制、髋部平行
  • ✗ 弓起下背 / 髋部旋转
登山者30s · 休30s
  • ✓ 手在肩正下方
  • ✓ 核心收紧防臀部过高
  • ✗ 臀部太高 / 弹跳
臀桥15次 · 休30s
  • ✓ 脚与髋同宽稳稳着地
  • ✓ 顶端挤压臀肌
  • ✗ 抬臀过高 / 膝盖内扣

补弱项（15 min）——上周最弱的部位

部位动作
腿弱靠墙静蹲 3×45s + 保加利亚分腿蹲 3×10/侧
背弱反向划船（桌下）3×8–12 + 弹力带下拉 3×15
肩弱弹力带肩推 3×10 + 面拉 3×15

拉伸（12 min）

  • 全身拉伸，重点放松本周练过的部位
